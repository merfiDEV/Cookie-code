# Улучшения панели Diff

## Что добавлено

### 1. **Навигация по hunks**
- Кнопки ◀ / ▶ для перехода между блоками изменений (`@@`)
- Хоткеи: `n` (next) и `p` (previous)
- Счётчик текущего hunk: `1 / 5`
- Автоскролл к активному hunk с плавной анимацией
- Подсветка активного hunk

### 2. **Внутристроковый diff**
- Алгоритм Myers на уровне символов
- Автоматическое определение пар `-`/`+` строк (замены)
- Подсветка изменённых символов внутри строки:
  - Зелёный фон для добавленных символов
  - Красный фон + перечёркивание для удалённых
- Работает только для строк < 200 символов (производительность)

### 3. **Копирование**
- Кнопка "Copy" — копирует весь diff в буфер
- Клик на строку — копирует её без префикса `+`/`-`
- Визуальная анимация при копировании (flash)
- Уведомление об успешном копировании

### 4. **Фильтры**
- Чекбоксы:
  - [ ] Added — показать только добавленные строки
  - [ ] Deleted — показать только удалённые
  - [ ] Context — показать контекстные строки
- Мгновенное применение фильтров
- Сохранение состояния фильтров между открытиями

### 5. **Мини-карта**
- Вертикальная полоса слева (12px)
- Цветные сегменты:
  - Зелёный — добавленные строки
  - Красный — удалённые
  - Синий — hunks
- Динамическое обновление при фильтрации

### 6. **Статистика**
- Строка в списке файлов: `📊 +234 -89 в 12 файлах`
- Показывается только если есть данные

### 7. **Кэширование**
- Кэш результатов: `Map<cacheKey, diffText>`
- Ключи:
  - `status:${filePath}` — для изменённых файлов
  - `commit:${hash}:${filePath}` — для файлов коммита
  - `full:${hash}` — для полного diff коммита
- Сброс кэша при открытии панели (кнопка обновления)

### 8. **Улучшенный UX**
- Hover-эффект на строках diff
- Клик на строку подсвечивает её
- Плавные переходы и анимации
- Курсор `pointer` на интерактивных элементах
- Более контрастная подсветка активного hunk

## Производительность

### Оптимизации
- Внутристроковый diff только для строк < 200 символов
- Кэширование результатов git-команд
- Ленивое обновление мини-карты (только при фильтрации)
- Debounce для хоткеев (встроенный в event listener)

### Будущие улучшения (не реализованы)
- Виртуализация для diff > 5000 строк (IntersectionObserver)
- Web Worker для Myers diff (не блокировать UI)
- IndexedDB для persistent кэша между сессиями

## Использование

### Хоткеи
- `n` — следующий hunk
- `p` — предыдущий hunk
- `Escape` — закрыть viewer (уже было)

### Копирование
- **Клик на строку** → копирует без префикса
- **Кнопка Copy** → копирует весь diff с префиксами

### Фильтры
- Работают независимо
- Meta и hunk строки всегда видимы
- Мини-карта обновляется автоматически
