# Changelog

## [4.0.26] - 2026-09-17

### Added

- **Telegram-бот: полноценный i18n (ru/en)** — все сообщения, меню и подписи бота переведены и вынесены в новый модуль `botsrc/i18n.js`:
  - язык бота хранится отдельно от языка UI (ключ `telegramLanguage` в `cuckoo-settings.json`), по умолчанию — системный;
  - при первом `/start` бот показывает выбор языка (кнопки 🇷🇺 Русский / 🇬🇧 English);
  - меню команд `/` в Telegram регистрируется через `setMyCommands` на выбранном языке.
- **Telegram-бот: приём вложений** — можно отправить боту фото или документ, он скачает файл и прикрепит его в поле ввода активного чата:
  - скачивание через `getFile` → `api.telegram.org/file/bot<token>/<file_path>` во временную папку `userData/tgtemp`;
  - изображения вставляются как картинка (clipboard + `Ctrl+V`, как у `read_photo`), остальные файлы — через `DataTransfer` + `change`;
  - MIME определяется по расширению, временный файл удаляется после прикрепления.
- **Telegram-бот: список сессий и переключение** — команды `/sessions` (постраничный список сессий проекта) и `/switch <id>` для переключения активной сессии.
- **Telegram-бот: пагинация длинных списков** — `/sessions`, `/log`, `/todos`, `/diff` разбиты на страницы по 10 элементов с кнопками «Назад / Вперёд».
- **Telegram-бот: новая команда `/todos`** — список задач активного окна с иконками статуса (`☐` / `◔` / `☑`) и пагинацией.
- **Telegram-бот: ограничение по User ID** — новая настройка `telegramAllowedUserId`: если задана, бот принимает сообщения только от этого пользователя (в дополнение к проверке `chat_id`).
- **Telegram-бот: игнор-лист уведомлений** — новая настройка `telegramToolNotifyIgnore` (список имён tool по одному в строке), уведомления о которых не отправляются. По умолчанию исключены «шумные» `read`, `readLines`, `glob`, `grep`, `todoWrite`.
- **Настройки: секция языка бота** — в меню `/settings` Telegram-бота добавлена отдельная страница «Язык» с выбором ru/en.

### Changed

- **Telegram-бот: меню настроек переведено на i18n и переструктурировано** — страницы (`ui`, `glass`, `agent`, `tg`, `lang`) собираются из локализованных ключей `label.*` / `settings.*`; лейблы кнопок и значения форматируются через `_t()`.
- **Рефакторинг `settings-tab.js`** — единый стиль (двойные кавычки, форматирование), переработаны привязки полей Telegram-настроек (добавлены `allowedUserId` и `notifyIgnore`), без изменения пользовательского поведения.
- **`botsrc/telegram.js`** — `configure()` принимает третий параметр `allowedUserId`; добавлены методы `setMyCommands()` и `downloadFile()`; long-polling пропускает сообщения без текста/фото/документа.
- **`settings-store.js`** — новые дефолты: `telegramLanguage`, `telegramAllowedUserId`, `telegramToolNotifyIgnore`; `telegramLanguage` подтягивается из системного языка, если пользователь его не выбирал.

### Fixed

- **Настройки Telegram: конфликт языка** — язык бота больше не перезаписывается языком UI; смена языка UI не влияет на язык бота (и наоборот).

### Removed

- Удалён вывод старых версий из CHANGELOG (оставлены только 4.0.26 и 4.0.25).

## [4.0.25] - 2026-09-17

### Added

- **Инструмент `attach_file` — загрузка файлов-вложений в чат** — AI может прикрепить локальный файл (PDF, Word, Excel, PPT, изображения и др. бинарные форматы) прямо в поле ввода:
  - скрытый `input[type=file]` на странице чата заполняется через `DataTransfer` + событие `change`;
  - лимит 30 МБ, авто-определение MIME по расширению (~50 типов, фолбэк `application/octet-stream`);
  - JS-API `attachFile(filePath)` (в песочнице также принимает объект `{ filePath }`), объявление в `cuckoo-tools.d.ts`, запись в `tool-names.js`;
  - окно определяется через callback `attachFile` (по аналогии с `pasteImage` у `read_photo`), а не через `BrowserWindow.fromId`.
- **Telegram-бот: индикатор «печатает…»** — во время генерации ответа AI в чат отправляется `sendChatAction('typing')` каждые ~4 секунды, статус гасится по завершении стрима. IPC-хэндлеры `telegram-typing-start` / `telegram-typing-stop`, обновлён `observer.js`.

### Changed

- **Задержка отправки — теперь в секундах** — в overlay-панели поля ввода переведены с миллисекунд на секунды (шаг 0.1):
  - хранение в `localStorage` и `state` осталось в мс (обратная совместимость с `chat-input.js`);
  - конвертация мс ↔ сек на границе UI, подпись `сек` / `sec`;
  - валидация и тосты переписаны под новые единицы.
- **i18n для настроек задержки** — сообщения об ошибках и сохранении переведены на ru/en (ранее были захардкожены на китайском): ключи `overlay.delay.*`.
- Исправлена вёрстка строки задержки в overlay — подписи «до» и «сек» больше не переносятся по буквам (отдельный класс `.cuckoo-delay-label` вместо `.cuckoo-blur-label` с `space-between`).
