# Changelog

## [4.0.34] - 2026-09-26

### Added

- 📤 **Инструмент `attach_telegram` — отправка файлов в Telegram** — AI может прикрепить любой локальный файл и отправить его прямо в чат с ботом:
  - JS-API `attachTelegram(filePath, caption?, comment?)`: `caption` — подпись к файлу, `comment` — то, что AI хочет добавить от себя (зачем файл, что внутри, на что обратить внимание);
  - если задан только `comment`, он уходит подписью; если заданы оба — `comment` дописывается к `caption` отдельной строкой;
  - лимит 45 МБ (запас под лимит Telegram в 50 МБ), подпись и комментарий обрезаются до 1024 символов;
  - отправка через уже настроенного бота (`telegramBot.sendDocument`) — новых зависимостей нет;
  - файлы больше лимита, отсутствующий файл или ненастроенный бот возвращают понятную ошибку;
  - объявление в `cuckoo-tools.d.ts`, обёртка `attachTelegram` в песочнице `JsRunner`.
- 📁 **Telegram-бот: выбор проекта кнопками** — новая команда `/projects` (алиасы `/project`, `/proj`) открывает список проектов inline-клавиатурой:
  - список собирается из сохранённых связок «сессия → проект» активного профиля, плюс текущий проект;
  - постраничный вывод по 8 проектов с кнопками «◀️ Назад / Вперёд ▶️» и счётчиком страниц;
  - выбор проекта переключает окно на **существующую сессию** этого проекта (та же навигация, что и `/switch`) — новый чат не создаётся;
  - кнопка «⌨️ Ввести путь вручную» принимает абсолютный путь к папке следующим сообщением;
  - если проект не выбран, команды `/diff`, `/log`, `/sessions` показывают сообщение вместе с клавиатурой выбора.

### Changed

- 📜 **`/log` и `/sessions` редактируют сообщение, а не плодят новые** — при повторном вызове и при листании страниц бот обновляет уже отправленное сообщение (`editMessageText`); если сообщение было удалено вручную — отправляется новое.
- 🆕 **`/new` сообщает результат** — вместо тишины или `⚠️ undefined` бот отвечает явно: «🆕 Новый чат открыт», «⚠️ Нет активного окна…» или «❌ Не удалось открыть новый чат: \<причина\>».
- 🌐 **Язык бота больше не навязывается** — `readSettings()` отдаёт ровно то, что записано в файле настроек, без подстановки языка системы; при `/start` бот больше не требует принудительно выбрать язык, а сразу показывает справку.

### Fixed

- 🐛 **`/new` не отвечал** — `newChat()` делает `loadURL` на домашнюю страницу и выгружает JS-контекст окна, поэтому `executeJavaScript` с ожиданием результата зависал навсегда. Теперь вызов «выстрелил-и-забыл», а ответ приходит сразу.
- 🐛 **Пагинация выбора проекта падала** — `ReferenceError: msgId is not defined` в обработчике callback-кнопок; id сообщения теперь берётся из `cbq.message`, а при неудачном редактировании есть фолбэк на отправку нового сообщения.
- 🐛 **Выбор проекта не применялся в приложении** — установка проекта по известному пути не переключала окно на его сессию. Добавлен IPC `set-project-dir` (+ `setProjectDir` в preload и `setProjectByDir` в main): поиск сессии по папке проекта и навигация на неё.
- 🐛 **Ошибка `setProjectDir недоступен в окне`** — метода не существовало; добавлен полный путь IPC → preload → main.

### Removed

- 🧹 **Принудительная фиксация языка DeepSeek** — удалён модуль `src/preload/dom/deepseek-language.js`, который переключал Language на «Система» и блокировал селект (`pointer-events:none`, `aria-disabled`, гашение `onMouseDown`/`onKeyDown`). Язык интерфейса DeepSeek снова выбирается пользователем свободно.

### Added (EN)

- 📤 **Tool `attach_telegram` — send files to Telegram** — the AI can attach any local file and send it straight to the chat with the bot:
  - JS API `attachTelegram(filePath, caption?, comment?)`: `caption` is the file caption, `comment` is an extra note the AI adds itself (why the file, what's inside, what to look at);
  - if only `comment` is given, it becomes the caption; if both are given, `comment` is appended to `caption` on a separate line;
  - 45 MB limit (headroom under Telegram's 50 MB cap), caption and comment are truncated to 1024 chars;
  - sent through the already-configured bot (`telegramBot.sendDocument`) — no new dependencies;
  - oversized files, a missing file, or an unconfigured bot return a clear error;
  - declared in `cuckoo-tools.d.ts`, wrapped as `attachTelegram` in the `JsRunner` sandbox.
- 📁 **Telegram bot: pick a project with buttons** — the new `/projects` command (aliases `/project`, `/proj`) opens a project list as an inline keyboard:
  - the list is built from saved "session → project" mappings of the active profile plus the current project;
  - paged output, 8 projects per page, with "◀️ Back / Next ▶️" buttons and a page counter;
  - picking a project switches the window to the **existing session** of that project (same navigation as `/switch`) — no new chat is created;
  - the "⌨️ Enter path manually" button accepts an absolute folder path as the next message;
  - if no project is selected, `/diff`, `/log`, and `/sessions` show the message together with the project picker.

### Changed (EN)

- 📜 **`/log` and `/sessions` edit the message instead of posting new ones** — on repeat calls and when paging, the bot updates the message it already sent (`editMessageText`); if the message was deleted manually, a new one is sent.
- 🆕 **`/new` reports the result** — instead of silence or `⚠️ undefined`, the bot answers explicitly: "🆕 New chat opened", "⚠️ No active window…", or "❌ Failed to open a new chat: \\<reason\\>".
- 🌐 **The bot language is no longer forced** — `readSettings()` returns exactly what is stored in the settings file, with no system-language substitution; on `/start` the bot no longer demands a language choice and just shows help.

### Fixed (EN)

- 🐛 **`/new` did not respond** — `newChat()` calls `loadURL` to the home page, which unloads the window's JS context, so `executeJavaScript` awaiting a result hung forever. The call is now fire-and-forget and the reply comes back immediately.
- 🐛 **Project picker pagination crashed** — `ReferenceError: msgId is not defined` in the callback-button handler; the message id is now taken from `cbq.message`, and a failed edit falls back to sending a new message.
- 🐛 **Project selection did not apply in the app** — setting a project by a known path did not switch the window to its session. Added the IPC `set-project-dir` (plus `setProjectDir` in preload and `setProjectByDir` in main): it finds the session by project folder and navigates to it.
- 🐛 **"setProjectDir is unavailable in the window" error** — the method did not exist; the full IPC → preload → main path was added.

### Removed (EN)

- 🧹 **Forced DeepSeek language lock** — deleted the `src/preload/dom/deepseek-language.js` module, which switched Language to "System" and locked the select (`pointer-events:none`, `aria-disabled`, neutered `onMouseDown`/`onKeyDown`). The DeepSeek UI language can be chosen freely by the user again.

- 🎨 **Свой цвет текста** — в разделе «Шрифт» появилась пипетка с HEX-полем, чтобы красить шрифт интерфейса и страницы в любой цвет:

  - кнопка **«Сбросить»** возвращает системный цвет;

- 📊 **Точный учёт сообщений в статистике** — сообщения теперь считаются по появлению в DOM (.ds-message) с двойной дедупликацией:
  - один DOM-узел учитывается ровно один раз (WeakSet);
  - стабильный хэш (роль + позиция) уходит в главный процесс, поэтому повторный рендер диалога при SPA-навигации туда-обратно не раздувает счётчики;
  - служебные сообщения Cookie Code (результаты инструментов, JS-сводки, контекст) больше не считаются пользовательскими.
- 📜 **Кодекс поведения** — добавлен bilingual CODE_OF_CONDUCT.md; в CONTRIBUTING.md появилась ссылка на него, а лицензия проекта исправлена на **MIT** (было указано GPL-3.0).

### Changed

- ⚡ **Превью в настройках больше не тормозят при пролистывании** — сетки фонов, шрифтов и чубриков перерисованы под лёгкий скролл:
  - картинки превью грузятся лениво — полноразмерный data-URI подставляется только при приближении плитки к экрану, а не для всех сразу;
  - невидимые плитки исключены из layout и отрисовки (content-visibility + contain);
  - убраны дорогие hover-анимации (подъём и тень), которые заставляли браузер перерисовывать плитки на каждом кадре прокрутки.
- 🎨 **Кастомный скроллбар в настройках** — полоса прокрутки панели настроек оформлена в стиле темы: тонкий трек, скруглённый бегунок с подсветкой при наведении (webkit + scrollbar-width/color для Firefox).
- ✨ **Плавное появление окна инициализации** — first-time диалог теперь открывается и закрывается с анимацией (fade + лёгкий подъём/масштаб бокса) вместо резкого появления.

### Fixed

- 🐛 **Дашборд на домашней странице прячется, пока в поле ввода есть текст** — начал набирать сообщение — дашборд тут же уходит с глаз долой; очистил поле — возвращается. Реакция мгновенная, покрывает textarea и contenteditable, включая ввод через IME (compositionend).

## [4.0.30] - 2026-09-18

### Added

- 🧪 **Инструмент `inject_page_js` — JS прямо на странице (как F12)** — AI может выполнять код в main world текущей страницы и получать результат:
  - по умолчанию работает в главном окне (там, где идёт чат), опционально — в любом окне, открытом через `open_browser_window`;
  - доступны DOM, `window.*`, `localStorage`, `fetch` от имени страницы — удобно собирать данные со страницы;
  - `window.electronAPI` в этом контексте недоступен (это честный main world);
  - код — либо блок с `return` в начале, либо выражение (например IIFE); поддержка `await`, результат JSON-совместимый.
- 🎛 **Тумблер «Показывать дашборд»** — статистику можно копить, но сам дашборд на домашней странице скрыть. Настройки → «Система и безопасность» → «Статистика»:
  - выключил — дашборд прячется мгновенно и больше не мешает; сбор статистики при этом продолжается;
  - включил обратно — дашборд тут же возвращается на своё место.

### Changed

- ⚡ **Дашборд стал заметно легче** — рендер оптимизирован, чтобы не грузить страницу:
  - DOM-скелет строится один раз, дальше обновляются только изменившиеся узлы (теплокарта трогает 1–2 ячейки вместо ~200);
  - обновление данных пропускается, если сводка не менялась, и не тянется вовсе, пока дашборд скрыт;
  - наблюдение за DOM дебаунсится, убраны дублирующиеся подписки — во время стрима ответа страница больше не дёргает дашборд сотни раз в секунду.

### Fixed

- 🐛 **Дашборд пропадал не сразу при входе в сессию** — при переходе в чат он висел ещё до 1.5 секунды. Причина: SPA-навигация идёт через `history.pushState`/`replaceState`, которые не вызывают `popstate`/`hashchange`. Теперь эти вызовы перехватываются, и дашборд скрывается мгновенно.

## [4.0.28] - 2026-09-17

### Added

- 🔤 **Шрифт на выбор — теперь и для интерфейса, и для самой страницы** — в настройках появилась отдельная секция «Шрифт»:
  - встроенный **Anthropic Mono** — выбирается одним кликом; по умолчанию всё работает на системном шрифте, ничего не навязывается;
  - **свои шрифты** — положи файлы `.ttf` / `.otf` / `.woff` / `.woff2` в папку (кнопка «Открыть папку шрифтов») и нажми «Обновить» — шрифт появится в сетке превью;
  - **слайдер жирности** (100–900) — работает и для системного, и для любого кастомного шрифта;
  - выбранный шрифт применяется мгновенно ко всему интерфейсу Cookie Code **и** к странице DeepSeek (иконки и эмодзи не ломаются).
- 🔁 **Перенос контекста в новый чат** — длинный диалог можно продолжить в свежем чате, не теряя наработок:
  - кнопка **«Перенести контекст»** в панели Cookie Code;
  - история текущего чата читается из DOM, **AI сжимает её в структурный конспект** (цель, решения, изменённые файлы, открытые вопросы);
  - вместе с конспектом в новый чат переносится **промпт инициализации проекта** (дерево каталога + системный промпт), поэтому AI сразу «знает» проект;
  - длинные истории автоматически подрезаются по оценке токенов (до 50 000).
- 🗂 **Настройки разбиты на категории** — вместо одной длинной простыни появились подвкладки: 🎨 Тема и стекло, 🪟 Панель Cookie, 🖼 Фон страницы, 🤖 Telegram-бот, ⚙️ Система и безопасность:
  - иконки подвкладок — аккуратные SVG (без эмодзи), рядом с «Cookie Code» — иконка печенья;
  - панель подвкладок прячется при прокрутке вниз и возвращается при прокрутке вверх.

### Changed

- **Иконки подвкладок настроек** — эмодзи заменены на инлайн-SVG, которые наследуют цвет кнопки (в т.ч. белый у активной).

### Fixed

- Перенос контекста: надёжное ожидание ответа AI (по появлению нового сообщения и стабилизации текста, а не только по кнопке «стоп») — больше не «зависает» на коротких ответах.
- Перенос контекста: промпт инициализации теперь **пересобирается в главном процессе** из сохранённого каталога проекта, поэтому не теряется при перезагрузке страницы.

### Added

- 🐦 **Чубрики прилетели на поле ввода!** Теперь на панели с сообщениями живёт твой питомец — сидит на верхней границе поля и переезжает вместе с ним. Никаких слетающих координат при смене разрешения: место посадки хранится в долях поля :)

- 📤 **Загрузить своего** — кнопка «Загрузить…» принимает любую картинку. Большие фото автоматом сжимаются до 600×600, чтобы не тормозить :3

## [4.0.26] - 2026-09-17

### Added

- **Telegram-бот: полноценный i18n (ru/en)** — все сообщения, меню и подписи бота переведены и вынесены в новый модуль `botsrc/i18n.js`:
  - язык бота хранится отдельно от языка UI (ключ `telegramLanguage` в `cuckoo-settings.json`), по умолчанию — системный;
  - при первом `/start` бот показывает выбор языка (кнопки 🇷🇺 Русский / 🇬🇧 English);
  - меню команд `/` в Telegram регистрируется через `setMyCommands` на выбранном языке.
- **Telegram-бот: приём вложений** — можно отправить боту фото или документ, он скачает файл и прикрепит его в поле ввода активного чата:
  - скачивание через `getFile` → `api.telegram.org/file/bot<token>/<file_path>` во временную папку `userData/tgtemp`;
  - изображения вставляются как картинка (clipboard + `Ctrl+V`, как у `read_photo`), остальные файлы — через `DataTransfer` + `change`;
  - MIME определяется по расширению, временный файл удаляется после прикрепления.
- **Telegram-бот: список сессий и переключение** — команды `/sessions` (постраничный список сессий проекта) и `/switch <id>` для переключения активной сессии.
- **Telegram-бот: пагинация длинных списков** — `/sessions`, `/log`, `/todos`, `/diff` разбиты на страницы по 10 элементов с кнопками «Назад / Вперёд».
- **Telegram-бот: новая команда `/todos`** — список задач активного окна с иконками статуса (`☐` / `◔` / `☑`) и пагинацией.
- **Telegram-бот: ограничение по User ID** — новая настройка `telegramAllowedUserId`: если задана, бот принимает сообщения только от этого пользователя (в дополнение к проверке `chat_id`).
- **Telegram-бот: игнор-лист уведомлений** — новая настройка `telegramToolNotifyIgnore` (список имён tool по одному в строке), уведомления о которых не отправляются. По умолчанию исключены «шумные» `read`, `readLines`, `glob`, `grep`, `todoWrite`.
- **Настройки: секция языка бота** — в меню `/settings` Telegram-бота добавлена отдельная страница «Язык» с выбором ru/en.

### Changed

- **Telegram-бот: меню настроек переведено на i18n и переструктурировано** — страницы (`ui`, `glass`, `agent`, `tg`, `lang`) собираются из локализованных ключей `label.*` / `settings.*`; лейблы кнопок и значения форматируются через `_t()`.
- **Рефакторинг `settings-tab.js`** — единый стиль (двойные кавычки, форматирование), переработаны привязки полей Telegram-настроек (добавлены `allowedUserId` и `notifyIgnore`), без изменения пользовательского поведения.
- **`botsrc/telegram.js`** — `configure()` принимает третий параметр `allowedUserId`; добавлены методы `setMyCommands()` и `downloadFile()`; long-polling пропускает сообщения без текста/фото/документа.
- **`settings-store.js`** — новые дефолты: `telegramLanguage`, `telegramAllowedUserId`, `telegramToolNotifyIgnore`; `telegramLanguage` подтягивается из системного языка, если пользователь его не выбирал.

### Fixed

## [4.0.25] - 2026-09-17

### Added

- **Инструмент `attach_file` — загрузка файлов-вложений в чат** — AI может прикрепить локальный файл (PDF, Word, Excel, PPT, изображения и др. бинарные форматы) прямо в поле ввода:
  - скрытый `input[type=file]` на странице чата заполняется через `DataTransfer` + событие `change`;
  - лимит 30 МБ, авто-определение MIME по расширению (~50 типов, фолбэк `application/octet-stream`);
  - JS-API `attachFile(filePath)` (в песочнице также принимает объект `{ filePath }`), объявление в `cuckoo-tools.d.ts`, запись в `tool-names.js`;
  - окно определяется через callback `attachFile` (по аналогии с `pasteImage` у `read_photo`), а не через `BrowserWindow.fromId`.
- **Telegram-бот: индикатор «печатает…»** — во время генерации ответа AI в чат отправляется `sendChatAction('typing')` каждые ~4 секунды, статус гасится по завершении стрима. IPC-хэндлеры `telegram-typing-start` / `telegram-typing-stop`, обновлён `observer.js`.

### Changed

- **Задержка отправки — теперь в секундах** — в overlay-панели поля ввода переведены с миллисекунд на секунды (шаг 0.1):
  - хранение в `localStorage` и `state` осталось в мс (обратная совместимость с `chat-input.js`);
  - конвертация мс ↔ сек на границе UI, подпись `сек` / `sec`;
  - валидация и тосты переписаны под новые единицы.
- **i18n для настроек задержки** — сообщения об ошибках и сохранении переведены на ru/en (ранее были захардкожены на китайском): ключи `overlay.delay.*`.
- Исправлена вёрстка строки задержки в overlay — подписи «до» и «сек» больше не переносятся по буквам (отдельный класс `.cuckoo-delay-label` вместо `.cuckoo-blur-label` с `space-between`).
