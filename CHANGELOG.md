# Changelog

## [5.0.4] - 2026-10-07

### Added

- 🧠 **Двухуровневая память AI** — теперь AI помнит и вас, и проект: раньше была одна общая память на всё, теперь их две, и каждая живёт там, где ей место:

  | Уровень       | Где хранится                                   | Что помнит                                                                                                                                                |
  | ------------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
  | 🗂 Проектная   | `<projectDir>/.cuckoo/memory/ProjectMemory.md` | Соглашения, архитектурные решения, важные пути, стек, договорённости. Едет вместе с репозиторием (папка в `.gitignore` — личные заметки AI не коммитятся) |
  | 🌍 Глобальная | `<userData>/memory.md`                         | Общие факты о вас и вашей системе: имя, ОС, GPU, предпочтения по стилю кода                                                                               |
  - 📖 `memory_read(scope?)` — прочитать: `'all'` (по умолчанию — проектная + глобальная), `'project'`, `'global'`;
  - 💾 `memory_save(text, scope?)` — сохранить. По умолчанию пишет в ==проектную память==, если проект инициализирован, иначе в глобальную; `scope='global'` — для фактов о пользователе;
  - 🗑 `memory_clear(scope?)` — очистить (только по прямой просьбе, AI предупредит);
  - 🎛 настройки памяти в UI тоже получили параметр `scope` — открытие файла, очистка и статистика работают отдельно для каждого уровня;
  - 🔗 в промпт AI подставляются ==абсолютные пути== к обоим файлам, а в JS-скриптах доступны как `globalThis.memoryPath` и `globalThis.projectMemoryPath`.

- ✅ **Кнопка «Коммит» в панели изменений** — собрать все diff разом и отправить в чат:

  | До                                                 | После                                                                                                            |
  | -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
  | Нужно было вручную копировать каждый diff по файлу | Одна кнопка склеивает unified diff **всех** изменённых файлов (включая untracked) и шлёт готовое сообщение в чат |
  - 📋 `git-diff-all` — новый IPC-хендлер, склеивает unified diff **всех** изменённых файлов (включая untracked);
  - 🤖 в чат уходит готовое сообщение с просьбой закоммитить — можно позвать агента `git-committer` или сделать самому. Кнопка со звёздочкой в шапке панели diff, после клика панель закрывается.

- 🛡 **`safeAsync` — безопасный запуск async-функций** в `src/preload/dom/safe.js`:
  - rejected Promise больше не «роняет» вызывающий пайплайн — ошибка логируется, а Promise резолвится в `fallback`;
  - учёт частоты падений по label (`failCounts`), throttle-ключ теперь включает текст сообщения — разные ошибки одного label не схлопываются;
  - `fallback` может быть функцией — вызывается безопасно, её падение наружу не пробрасывается.

### Changed

- 🎨 **Иконки обновления в оверлее** — эмодзи 🔄 заменены на ==SVG-иконки== (кнопки обновления MCP и панели diff). Чётче выглядит, не зависит от шрифта системы.
- 📝 **Промпт субагента: «1–2 инструмента за раз»** — в задание агенту добавлена просьба не вызывать сразу пачку инструментов. Меньше шума в логах, аккуратнее шаги.
- 🧹 **Чистка репозитория** — удалён спрайт `assets/петы.jpg` и его секция из `README.ru.md` (питомцы больше не документируются).

### Fixed

- 🐛 **Async-ошибки в `safe()` больше не теряются** — sync-путь работал, а Promise-результат при падении давал unhandledRejection. Теперь оба пути перехватываются одинаково.
- 🐛 **Панель diff закрывается после клика «Коммит»** — кнопка вставляла diff в чат, но окно оставалось висеть поверх. Теперь `closeDiffPanel()` вызывается сразу после отправки.
- 🐛 **Глобальная память не теряется при работе без проекта** — `getMemoryPath` теперь принимает `scope` и `projectDir`, для глобального уровня `projectDir` не нужен. IPC-хендлеры аккуратно возвращают ошибку, если проект не инициализирован, а не падают.

### Removed

- 🗑 **`app.setName("Cookie Code")`** из `src/main/index.js` — принудительная установка имени в dev-режиме убрана.
