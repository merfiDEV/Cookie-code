# Changelog

## [4.0.24] - 2026-09-16

### Added

- **Цветные иконки файлов (Material Icon Theme)** — рядом с именами файлов теперь рисуется иконка по типу файла (расширению/имени):
  - в чипах путей внутри ответов AI;
  - в блоке «Затронуто» под ответом;
  - в меню @-упоминаний файлов.
    Иконки берутся из пакета `material-icon-theme` (~1377 расширений, ~2135 спец-имён) через IPC `get-file-icons`; неизвестные типы показывают контурный документ.
- **Регистронезависимый @-поиск файлов** — `@lua` находит `Sample.LUA` и наоборот (в ripgrep для `@`-поиска используется `--iglob` вместо регистрозависимого `--glob`).

### Changed

- **Меню slash-команд `/`** оставлено без иконок — иконки показываются только в списке файлов (`@`).
- Список файлов в меню `@` выровнен по левому краю с иконкой 16×16 (папка — SVG, файл — Material-иконка).

## [4.0.20] - 2026-09-16

### Added

- **Telegram-бот: команды управления** — теперь из Telegram доступны:
  - `/status` — статус окна, проекта, процессов, задач и polling бота
  - `/stop` (синоним `/kill`) — прервать текущую задачу и убить активные дочерние процессы
  - `/new` — открыть новый чат на домашней странице провайдера
  - `/diff` — прислать `git diff` текущего проекта (до 3 КБ суммарно, с картой файлов)
  - `/diagnostics` (синоним `/diag`) — отчёт диагностики интеграции main/preload/сайта
- **Telegram-бот: очередь сообщений** — исходящие сообщения идут через очередь с троттлингом ~1 сообщение/сек на чат (уважает лимит Telegram)
- **Telegram-бот: retry на 429** — при rate-limit соблюдается `retry_after` из ответа Telegram, до 3 попыток на запрос
- **Telegram-бот: файловый лог** — `<userData>/telegram-bot.log` с ротацией при 512 КБ (переименование в `.1`), уровни info/warn/error; дублирует вывод в консоль
- **Telegram-бот: маскировка токена** — все сообщения и логи проходят через `TelegramBot.maskToken()`, токен заменяется на `bot<TOKEN>`
- **`/cancel` отменяет и подтверждения** — теперь сбрасывает не только ожидающий ввод, но и все pending-approval вызовы инструментов
- **`/settings`** — обновлена справка `/help` со всеми новыми командами
- **IPC `new-chat`** — новый обработчик + `window.electronAPI.newChat()` (переход на домашнюю страницу активного провайдера)
- **`window.electronAPI.runDiagnosticsText()`** — запуск диагностики в контексте страницы, возвращает готовый текстовый отчёт
- **Сайт проекта на GitHub Pages** (`docs/`) — лендинг в Material Design 3:
  - тёмная тема, голубые акценты, Material Symbols Outlined
  - версии на русском (`index.html`) и английском (`en.html`) с переключателем языка
  - галерея скриншотов с lightbox (клик / Esc)
  - секции: hero, «зачем», возможности, таблица инструментов, установка, использование, конфигурация, CTA
  - готов к публикации через Settings → Pages → `/docs`
- **prettier** добавлен как devDependency

## [4.0.19] - 2026-09-15

### Added

- **Учёт токенов диалога**: панель «Токены диалога» с оценкой всего диалога из DOM (CJK 0.6 / ASCII 0.3), сохранение по `sessionId` в localStorage, обновление раз в секунду, на `popstate`/`hashchange` и `beforeunload`; формат K/M вместо китайского «万»
- **Токены под ответом AI**: оценка токенов именно этого ответа под каждым сообщением
- **Перехват серверных токенов DeepSeek** (`token-interceptor`): точные значения usage из ответов DeepSeek + настройка видимости
- **What's New**: модальное окно нововведений при первом запуске после обновления
  - `src/main/changelog-parser.js` — парсер CHANGELOG.md (диапазон версий, semver-сравнение)
  - `src/main/whats-new.js` — логика check-and-mark, атомарная запись состояния
  - `src/preload/dom/whats-new.js` — одноразовый модал в рендерере; CHANGELOG.md включается в сборку
- **Диагностика интеграции** (`src/preload/dom/diagnostics.js`) — инструмент и UI проверки связки main/preload/сайт

### Changed

- **Удалён Claude-провайдер** (`src/providers/claude.js`, промпт, лого, тесты)
- Удалён мёртвый код network-hook (`src/interceptor/`, `intercept-observer.js`, `serverTokenUsage`, `useIntercept`)
- Обновлён UI вкладки настроек (`settings-tab.js`)
- Убран устаревший хелпер tryOpenInVSCode

## [4.0.18] - 2026-09-14

### Added

- **Авто-форматтеры** после `write`/`edit`: файл автоматически приводится к стилю проекта
  - Встроенный реестр: prettier, biome, gofmt, ruff, rustfmt, shfmt, clang-format
  - Определение по расширению + наличию конфига + бинарю в `PATH` или `node_modules/.bin`
  - Отключается флагом `formattersEnabled: false` в `cuckoo-settings.json`
  - Ошибки форматтера никогда не ломают `write`/`edit`
  - Кнопка вкл/выкл в настройках Cookie Code; документация в README (EN + RU)
- **Режим плана (Plan Mode)**: кнопка-тумблер, per-session режим, перетаскиваемый диалог плана, инструмент `exit_plan_mode`
- **Produced files** под ответом AI (факт-ориентированно, только успешные операции), ru/en i18n, настройка `showProducedFiles`, тесты
- **Бейджи +/− строк** по каждому блоку diff в ответе
- **Telegram-бот**: команды `/help` и `/settings` с полным меню настроек

### Fixed

- `meta.produced` label: «Создано» → «Затронуто» / Produced → Affected
- i18n overlay: `OVERLAY_HTML` → `buildOverlayHTML()` — пересборка при смене языка
