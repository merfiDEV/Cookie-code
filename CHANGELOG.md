# Changelog

## [5.0.9] - 2026-10-26

### Added

- ⛔ **Уведомление в Telegram при rate-limit DeepSeek (429 / 40029)** — при превышении лимита запросов в Telegram приходит ==КАПС-предупреждение== с просьбой подождать:
  - в main-world перехватчике `token-interceptor-inject.js` в патчах `fetch`/`XHR` ловятся HTTP `429` и бизнес-код `40029` (`IP_ACCESS_RESTRICTED`) в теле ответа;
  - событие уходит через `postMessage({ __cuckoo: "rate-limit" })`, preload слушает с антиспамом 60с;
  - IPC `telegram-rate-limit` → `botsrc.notifyRateLimit()` шлёт сообщение с ожиданием 5–20 минут (учёт `retry-after` при наличии);
  - строки локализации `rateLimit.*` (ru/en) в `botsrc/i18n.js`; в окнах-субагентах уведомление подавляется.
- 🔄 **Pull-модель получения initial-prompt в окне субагента** — если push потерялся из-за гонки IPC, окно само запрашивает промпт у main:
  - `subagent.js` кэширует combined-промпт по `windowId` и отдаёт через `getInitPrompt()`;
  - новый IPC-хендлер `subagent-get-init-prompt` в `src/main/ipc.js`;
  - в `chat-input.js` окно-субагент через 20с запрашивает промпт, если не получило пушем.

### Changed

- 🪟 **Отправка initial-prompt в субагент стала устойчивее** — повторные отправки в `3с / 8с / 15с`, абсолютный таймаут до 3 минут (было: 1.2с и 60с) в `subagent.js`.
- ⏳ **Ожидание поля ввода в окне субагента** — увеличено с ~15с до 90с (180 попыток × 500мс), `pendingInitialPrompt` больше не сбрасывается по таймауту (`chat-input.js`).
- 🛡 **Защита от дубля initial-prompt** — `applyInitialPrompt()` с флагом `_initialPromptApplied` не даёт отправить промпт дважды (push + pull).

### Fixed

- 🐛 **Окно субагента больше не остаётся пустым без промпта** — повторные отправки + pull-запрос закрывают гонку долгой загрузки окна.
- 🧹 **DSML/XML-мусор в ответе субагента не считается финальным ответом** — проверка вынесена ==выше анализа cuckoo-блоков== (`subagent-watch.js`):
  - детект по `textContent` **и** `innerHTML` (ловит мусор внутри `<pre>` и когда теги съедены markdown-рендером);
  - паттерны: маркеры `DSML`, `invoke/parameter/tool_calls name=` с тегом и без;
  - при обнаружении в чат уходит предупреждение (на английском) использовать `cuckoo`-блок, ответ не завершается; лимит 3 подсказки + антидубль по снапшоту.

## [5.0.8] - 2026-10-22

### Added

- 💬 **Inline-комментарии к строкам плана с обратной связью ИИ** — в диалоге утверждения плана (`exit_plan_mode`) можно ==комментировать отдельные строки==, не отклоняя план целиком:
  - выделите фрагмент плана → появляется кнопка «💬» → откроется поле ввода под нужным блоком;
  - комментарии помечают строку подсветкой и сохраняются с привязкой к тексту строки;
  - при одобрении комментарии прикладываются к запросу и ==автоматически отправляются== в чат;
  - при отклонении комментарии возвращаются модели как замечания.
- 📝 **Панель промптов проекта** — сохранённые промпты в `.cookie/prompts/*.md`:
  - кнопка «Промпты» в оверлее: создать / изменить / удалить и вставить текст в поле ввода;
  - хранилище `prompts-store.js` + IPC `prompts-list` / `prompts-save` / `prompts-delete`.
- 🤖 **Команда `/prompts` в Telegram-боте** — список с кнопками «Вставить» / «Удалить» и «Создать» с пошаговым вводом; локализация ru/en, команда в `/help` и меню.
- 📜 **Система правил проекта `.cookie/rules.md`** — инструмент `readrules()` и гейт `rules-gate.js`: до принятия правил разрешены только `read` / `read_lines` / `file_read` / `memory_read` / `readrules`; нет файла — нет блокировки; субагенты без гейта.
- 🌍 **Глобальные Skill** — скиллы ищутся в `<userData>/skills/` и `<projectDir>/.cuckoo/skills/`; глобальный перекрывает проектный.

### Changed

- 🗂 **Проектная память переехала в `.cookie/memory/`** — `<projectDir>/.cookie/memory/ProjectMemory.md` (`memory-store.js`, `MemoryTool.js`, README ru/en).
- 🪟 **Выбор git-ветки** — изолированные CSS-классы `.cc-branch-btn`: глобальные стили DeepSeek больше не режут текст кнопок.
- 📖 **Документация** — README (ru/en/осн.) дополнены разделами про правила, скиллы, промпты и режим плана.

### Fixed

- 🐛 **Ответ `ask_user_question` всегда виден в выводе** — попадает в лог даже без `log()`, без дублирования.

## [5.0.7] - 2026-10-15

### Added

- 🎯 **Режим цели `/goal` — автономные многораундовые задачи** — одна команда превращает задачу в самодвижущийся цикл: AI шаг за шагом продвигается к цели ==без вашего участия между шагами==:
  - раунд завершился (нет tool-вызовов) — Cookie Code **сам** отправляет AI «продолжай» через задержку `NUDGE_DELAY`;
  - движок живёт в preload (`goal-engine.js`), состояние per-session, персистится в `localStorage` (`cuckoo-goal-v1`);
  - завершение — когда AI вызывает инструмент `goalDone()`;
  - предохранители: лимит итераций (по умолчанию 50, настройка `cuckoo-goal-max-iterations`) и остановка при 3 раундах без прогресса (`NO_PROGRESS_LIMIT`).
- ⌨️ **Перехват команды `/goal` в веб-чате** (`goal-command.js`) — команда ловится на capture-фазе (Enter и клик по кнопке отправки) и обрабатывается локально, в AI не уходит:
  - `/goal <описание>` — задать цель;
  - `/goal` — показать статус;
  - `/goal stop | pause | resume` — управление.
- 🪟 **Плавающая панель «Цель»** (`goal-panel.js`) — слева появляется перетаскиваемая карточка с текстом цели, номером итерации, таймером и кнопками **Пауза** / **Выход**:
  - стили встроены в overlay (`template.js`), цвет статуса меняется по состоянию (`running` / `paused` / `done`);
  - позиция панели сохраняется в `localStorage` (`cuckoo-goal-pos`).
- 🤖 **Цель в Telegram** — команда `/goal` в боте умеет задавать цель, показывать статус и управлять ею (`stop` / `pause` / `resume`):
  - в чат приходит человеческое уведомление о старте и о завершении цели (`notifyGoalDone`);
  - статус читается из `goal-store` в main по активному окну.
- 🧰 **Инструмент `goal_done`** (`GoalDoneTool.js`) — AI вызывает `goalDone()`, чтобы объявить цель выполненной; тул шлёт IPC `goal-done` в окно, и движок останавливает цикл (заменяет текстовый маркер `[[GOAL_DONE]]`, который модель забывала писать).

### Changed

- 🍪 **Логотип и README** — в README (ru/en/осн.) добавлен блок про режим цели; в таблицу инструментов добавлен `goalDone`.
- 📖 **Команда `/goal` в help бота** — в списке команд появились `/goal <цель>` и `/goal stop|pause|resume` (ru/en).

### Fixed

- 🐛 **Snake_case алиас `goal_done`** — наряду с `goalDone()` в `JsRunner` зарегистрирован `goal_done`.
