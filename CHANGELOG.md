# Changelog

## [5.0.5] - 2026-10-10

### Added

- ✍️ **Свой ответ на вопросы от ИИ в Telegram** — теперь на каждый вопрос бота есть не только готовые варианты, но и кнопка ==«Свой ответ»==:
  - нажатие переводит бота в режим ожидания текста, ответ приходит следующим сообщением;
  - пустой ввод не принимается — бот попросит текст или «Отказаться»;
  - ожидание корректно снимается при `/cancel`, отказе от вопроса и когда вопрос уже закрыт.

- 🔔 **Свои MD3-уведомления с ответом прямо из карточки** — системный `Notification` заменён на кастомное окно в стиле Material Design 3 (правый нижний угол, тёмная карточка, tonal-иконка, статус-точка, hover-подъём):
  - встроенное поле ответа — печатаете, жмёте Enter или ➤, текст уходит ==прямо в чат== Cookie Code;
  - пока печатаете, авто-скрытие откладывается (`cuckoo-notif-hold`);
  - клик по карточке фокусирует главное окно; если окно уже в фокусе — уведомление не показывается вовсе.

- 🤖 **Уведомление о результате субагента** — когда субагент завершился или упал по таймауту, приходит та же MD3-карточка с именем агента; клик фокусирует родительское окно, ответ уходит в родительский чат.

- 🖼 **Diff картинками в Telegram** — команда `/diff` теперь рендерит diff каждого файла в ==PNG== и шлёт их альбомами (`sendMediaGroup`, пачки по 10, рендер в пуле из 3 окон). Плюс кнопка «Попросить коммит и пуш» с выбором ветки:

  | Было                                 | Стало                                                    |
  | ------------------------------------ | -------------------------------------------------------- |
  | Огромный текстовый `<pre>` с diff-ом | Цветные картинки: зелёные `+`, красные `-`, мета и ханки |
  | Не было выбора ветки                 | Кнопки `git branch -a` — `✓` текущая, `☁` удалённая      |

  После выбора ветки бот шлёт в чат готовый промпт с указанием ветки.

- 🌿 **Выбор ветки в панели diff приложения** — кнопки «Коммит» и «Ветка» объединены в одну: открывается пикер веток, по выбору в чат уходит просьба закоммитить и запушить именно в неё:
  - новые `listBranches()` / `currentBranch()` в `git-diff.js`;
  - IPC `git-list-branches` и `git-current-branch`.

- 🖥 **Выбор окна для `/screen`** — если запущены живые субагенты, `/screen` показывает меню: **Main** + кнопка на каждого субагента (с именами, при дублях — `#1`, `#2`). Скриншот уходит с подписью, какое именно окно снято.

- 📋 **Карточка задач `todoWrite` в Telegram** — вместо технической строки приходит человеческая карточка с заголовком, счётчиком «Задач: N · выполнено: M» и разворачиваемым чек-листом (`☐ ◔ ☑`). `todoWrite` убран из `telegramToolNotifyIgnore`, чтобы карточка приходила всегда.

- 📨 **Команда `/send`** — нажать кнопку отправки в активном окне чата, если авто-отправка зависла и текст остался в поле:
  - есть и в боте, и в UI приложения как команда-действие `/send`;
  - кнопка ищется рядом с полем ввода, при неудаче отправляется нативный Enter.

### Changed

- 🎨 **Стиль переливания ника настраивается** — рядом с чекбоксом переливания появился селект стиля:
  - ==RGB (радуга)== — прежний вариант;
  - ==Кровь (чёрно-красный)== — новый тёмный градиент;
  - выбор сохраняется в настройке `rgbUsernameStyle`.
- 🍪 **Новый логотип и иконка приложения** — квадратный логотип 1024×1024 и многоразмерный `.ico`; в README (ru/en/осн.) добавлен по центру блок с иконкой, у русского README в заголовке появился 🍪.
- 🧹 **README: убран список горячих клавиш-петов** — таблица хоткеев сокращена до актуальной `F1` (управление петом больше не документируется).

### Fixed

- 🐛 **Переливание ника не анимировалось** — шорткат `background` с `!important` сбрасывал `background-position` и замораживал keyframes. Перешли на `background-image`, анимация снова бежит.
- 🐛 **Snake_case алиасы для агентов** — `list_agents` и `read_agent` теперь работают наравне с `listAgents`/`readAgent` (в `JsRunner` добавлены алиасы).
